# Privacy / identity-clean contribution policy

This public repository is intentionally identity-clean. Contributors should avoid committing or attaching:

- real names, personal e-mail addresses, phone numbers, or account identifiers;
- absolute host paths such as `C:\\Users\\...` or `/home/...`;
- cloud-storage IDs or private share links;
- raw terminal logs that reveal usernames or local directory layouts;
- Git metadata copied from a private working tree;
- save files or screenshots that may contain personal information.

Diagnostic tools may print paths or values supplied by the caller, so generated logs should be reviewed before they are posted publicly.
