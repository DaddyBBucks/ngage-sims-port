# Public release audit

Date: 2026-08-26

## Release model

This public tree was assembled by allow-listing original project source files
into a new directory. It does not reuse the private repository's `.git`
directory or commit graph. The public repository begins with one clean root
commit.

## Included

- Original Python harness and compatibility-layer source
- Original research instrumentation and archive-analysis utility source
- Independently produced import address/ordinal mapping (`thunk_map.json`)
- Dependency declaration and public-facing documentation
- MIT license for the original material in this public repository

## Excluded

- Game executable (`lxce_candidate.bin`) and all other game binaries
- `thesims.dat`, save files, ROM/firmware images, Symbian/N-Gage DLLs
- IDA/Ghidra databases and symbol exports derived from those databases
- Extracted game assets and the complete internal archive filename manifest
- Framebuffer/memory dumps, screenshots, videos, logs, caches, and outputs
- Historical private reports and the private repository's complete Git history

## Checks performed

- Python syntax compilation for every included Python module: passed
- Allow/deny extension and MIME-type inspection: passed after generated bytecode cleanup
- Files larger than 1 MiB: none
- Common credential/private-key pattern scan: no matches
- Personal email/name/home-directory pattern scan: no matches
- Git object integrity (`git fsck --full`): passed
- Complete committed-object extension/content scan: passed
- ZIP integrity (`unzip -tq`): passed
- Clean clone HEAD comparison and syntax compilation: passed
- Missing-input behavior: source-level guard verified; a full CLI smoke test was
  not executed in the packaging environment because Unicorn is not installed
  there. Runtime dependencies are declared in `requirements.txt`.

## Residual considerations

This is a technical publication audit, not legal advice or a legal guarantee.
`thunk_map.json`, numeric addresses, ordinals, and short behavioral descriptions
are retained as independently produced interoperability facts. If a maintainer
wants the most conservative possible release, `thunk_map.json` can instead be
generated locally and omitted, at the cost of making the source less usable.

It does not grant rights to any third-party game, firmware, asset, trademark,
or locally supplied input.
